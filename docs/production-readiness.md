# 生产可用性清单

本清单以当前明确支持的**单后端实例、SQLite 数据卷**部署为边界。  
“完成”表示代码、测试和部署校验均已落地，而不是仅有配置说明。

## P0：上线阻断项

| 项目 | 状态 | 证据 |
|---|---|---|
| 生产配置启动校验 | 完成 | 弱密钥、默认管理员口令、关闭鉴权、通配 CORS 会拒绝启动 |
| 首次登录强制改密 | 完成 | 管理员首次访问业务页面前必须修改初始化口令 |
| 登录与分享口令防爆破 | 完成 | 账号/IP 指数退避、`Retry-After`、进程内状态有界 |
| 分享令牌泄露防护 | 完成 | 数据库只存 SHA-256 摘要；明文仅在创建响应出现一次 |
| HTTPS 与端口暴露 | 完成 | 可选 Caddy TLS profile；默认只绑定环回地址 |
| SQLite 备份恢复 | 完成 | 在线备份、完整性校验、WAL 处理、安全副本、恢复后 readiness 检查 |
| 优雅排空和健康探针 | 完成 | `/live`、`/ready`、排空接口与发布脚本 |
| 断线重连续会 | 完成 | WebSocket 记住服务端 `meeting_id`，重连不新建会议 |
| AI 成本与审计 | 完成 | LLM 用量/成本落库、审计哈希链、请求 ID |

## P2：扩容与高可用

以下项目**不属于当前单机部署的 P0/P1**，只有切换到多实例/多节点时才需要：

- PostgreSQL 与 `FOR UPDATE SKIP LOCKED` 任务领取；
- Redis 共享登录限流、分享限流、活跃会话和排空状态；
- WebSocket 粘性路由或跨实例会话转发；
- 对象存储承载音频、导出和离线备份；
- 独立 worker 节点与模型推理服务池；
- 跨机备份、灾备演练和 RPO/RTO 目标。

在这些改造完成前，不要对同一个 SQLite 数据卷启动多个 backend 副本。
